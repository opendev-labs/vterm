🚀 Local Installation

Run VTerm on your own hardware for maximum performance and privacy.

# Clone the repository
git clone https://github.com/opendev-labs/vterm.git

# Enter the directory
cd vterm

# Install dependencies
npm install

# Start the server
npm start

🔗 Local Bridge Setup

The Local Bridge allows you to use the VTerm Cloud interface to control your local machine. This is ideal for developers who want a premium UI for their local shells.

  1. Ensure VTerm is running locally (npm start) on port 4000.
  2. Visit vterm.onrender.com.
  3. Choose Local Bridge on the login screen.
  4. The default URL is http://localhost:4000. Click Connect.

⚙️ Configuration

VTerm can be customized via environment variables to suit your production needs.

Variable Description Default
PORT The port the server listens on 4000
ADMIN_PASSWORD Password for Cloud Mode access vterm123
SESSION_SECRET Key used to sign session cookies vterm-secret

🛠 Troubleshooting

Port already in use

If you see EADDRINUSE, another process is using port 4000. Kill it using:

fuser -k 4000/tcp
